## What this establishes

Phase 4 adds 68 tests, including parameterized cases, over Phase 3's 155 tests.
Every implemented geometry evaluator has both a specific injected mismatch and a
legitimate supported-motion fixture. Timing tests cover nominal 20 TPS, sustained
25 TPS, constant latency, brief bunching, silence/burst and clearing debt after lag.
Buffer tests cover isolated/repeated samples, cooldown, time decay and nanoTime wrap.
Dispatcher tests cover uncertain diagnostics, exemptions, independent check disablement,
bounded evidence, complete-generation reset and timing windows between movement packets.

Safe-position tests cover trusted synthetic streaks, uncertain candidates,
world/session revision and expiry. Monitor and pipeline tests cover high ping vs
actual impairment, owner/world exemptions, local vs other-entity velocity,
teleport, runtime geometry uncertainty, synthetic jump replay, queue loss,
reload, disconnect/reconnect and rotation-only reports. Configuration tests cover
additive old-file preservation, atomic valid/invalid reloads and refusal to enable
missing models. MockBukkit verifies catalog/commands/permissions and confirms that
operators do not automatically receive bypass. All Phase 1–3 tests still execute.

The replay inputs are synthetic; the jump pipeline fixture is generated by the
project's physics engine, so it is a regression test, not independent conformance
evidence. No real-client trace was recorded.

`verifyPluginJar` loaded the shaded jar with a JDK-only parent classloader and
created all 24 YAML documents. It verified relocation and exclusion of server APIs,
PacketEvents, Netty and unrelocated SnakeYAML. Additional archive inspection
confirmed the new check/monitor/safe-position classes, API evidence record,
movement defaults, bypass permissions and expanded version descriptor.
`git diff --check` and source whitespace checks passed.

## Coverage limits

15 evaluators are implemented; NoSlowA, ElytraA and VehicleA remain unavailable
and configuration rejects enabling them. Full Phase 4 special-mechanic coverage
is not complete. Runtime geometry stays diagnostic because client world/input are
unacknowledged; it cannot generate trusted buffer increments or verified safe
positions. There are no setbacks, cancellations, kicks, bans or global risk engine.

Live Paper/Spigot/Purpur, proxy translation/Geyser, Folia, independent client
replays, production accuracy, large-server benchmarks and remote GitHub Actions
execution remain unverified. Folia remains rejected. Read `PHASE4.md` and `CHECKS.md`.
